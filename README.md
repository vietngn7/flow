## 🎯 Quick Start

### Для разработки продукта:
1. Читай **02-product-concepts/productivity_companion_concept_v2.md**
2. Смотри научную базу в **01-research/** по конкретным фичам
3. Используй шаблоны из **03-planning-templates/** для тестирования

### Для изучения research:
1. Начни с **01-research/концепции-продуктивности-научная-база.md**
2. Дальше по интересующим темам:
   - Сложные задачи → `преодоление-аверсивных-задач.md`
   - Эмоции/стресс → `managing-emotional-dysregulation.md`
   - Recovery → `rest-and-recovery-for-knowledge-workers.md`
   - Work-life balance → `segmenters-and-integrators-time-planning.md`
