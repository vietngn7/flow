## 🎯 Core Principles (Cross-Cutting)

### 1. Preference-Supply Fit > Universal Solutions
**Finding**: Match между individual preferences и system важнее абсолютного подхода
**Evidence**: r=0.57 work-life balance, r=-0.62 work-life conflict (Bogaerts, N=802)
**Implication**: Персонализация критична - нет универсального "правильного" способа

### 2. Progress Principle (Most Powerful Motivator)
**Finding**: Progress in meaningful work = #1 driver positive emotions & next-day performance
**Evidence**: 12,000 diary entries, 238 employees (Amabile)
**Implication**: Daily progress tracking важнее recognition, incentives, interpersonal support

**Critical**: Setbacks имеют 2-3x stronger negative impact чем equivalent progress positive
→ Evening review должен celebrate wins И process setbacks constructively

### 3. Planning Fallacy
**Finding**: Люди систематически недооценивают время на задачи
**Evidence**: Robust cross-studies (Buehler, Griffin, Ross)
**Implication**: Bot должен спрашивать: "Сколько РЕАЛЬНО нужно времени?" и track predicted vs actual

## 🚀 P0 Features (Must-Have, Phase 1)

### 1. Implementation Intentions (IF-THEN Planning)

**What**: "IF [situation], THEN [action]" создает automatic cue-response links

**Evidence**:
- d=0.65 (Gollwitzer & Sheeran 2006, 94 studies)
- Updated: d=0.27-0.66 across outcomes (Sheeran 2024, 642 tests)
- Behavioral outcomes strongest: d=0.66

**Critical Moderators**:
- ✅ Specific IF-THEN format (не просто "я планирую")
- ✅ High goal commitment изначально
- ✅ Rehearse план хотя бы 1 раз
- ✅ Face-to-face delivery для некоторых контекстов

**Boundary Conditions**:
- ⚠️ Работает лучше для one-time actions, хуже для repeated behaviors
- ⚠️ Physical activity: g=0.24-0.31 at follow-up (меньше чем initially)
- ⚠️ Не работает при слабом goal commitment

**Product Implementation**:
```
После Top-3 selection:

Bot: "IF-THEN планы увеличивают выполнение на 65%."

For each task:
┌─ IF-THEN BUILDER ────────────┐
│ Task: Презентация            │
│                              │
│ IF (trigger):                │
│ - Время: [9:00 AM]           │
│ - Место: [За компом]         │
│ - Событие: [После кофе]      │
│                              │
│ THEN (first action):         │
│ [Открыть Google Slides]      │
│                              │
│ ⚡ Rehearse: Visualize it    │
│    happening tomorrow        │
└──────────────────────────────┘

Bot: "Прорепетируй мысленно 1 раз!"
```

**Key Insight**: Bypass deliberation → automation → меньше cognitive load

### 2. Segmenter/Integrator Personalization

**What**: Preference для work-life separation vs blending

**Evidence**:
- Fit: r=0.57 work-life balance, r=-0.62 conflict (Bogaerts, N=802)
- ΔR²=0.09-0.14 unique variance beyond workload (9-14%!)
- Asymmetric: Excess segmentation when want integration = harmful, but less than reverse

**Who Are They**:

**Segmenters (40-60%)**:
- Prefer impermeable boundaries
- Benefit from: separate calendars, clear temporal boundaries, technology restrictions
- Higher stress when boundaries blur (r=0.30-0.40)
- More vulnerable to work-life conflict from interruptions

**Integrators (40-60%)**:
- Prefer permeable boundaries
- Benefit from: unified views, flexible scheduling, seamless transitions
- BUT: Even integrators need psychological detachment for recovery (Althammer RCT)

**Moderators**:
- Group norms amplify effects (γ=-0.43, Yang 2019)
- Life stage (caregiving ↑ segmentation need)
- Job autonomy (individual-control flexibility = positive)

**Product Implementation**:
```
Onboarding Quiz (Kreiner's 4-item scale):

1. "Тебе звонит семья в рабочее время. Как чувствуешь?"
   [😤 Раздражен] [😊 Норм, могу переключиться]

2. "Предпочитаешь думать о работе вне рабочего времени?"
   [Never] [Sometimes] [Often]

3-4... [еще 2 вопроса]

Result: "Ты SEGMENTER!"
→ System настраивается:
  - Separate work/personal planning spaces
  - Strict time boundaries
  - Technology restrictions evening
  - Minimal cross-domain visibility

Result: "Ты INTEGRATOR!"
→ System настраивается:
  - Unified view all commitments
  - Flexible windows
  - Seamless transitions
  - PLUS: mindfulness training для detachment
```

**Key Insight**: Fit matters more than absolute preference. Misfit = highest stress.

### 4. Emotional Dysregulation Protocol (Box Breathing)

**What**: Quick recovery from stress/frustration/tilt

**Evidence**:
- Box breathing: g=-0.35 stress reduction (N=785 meta-analysis)
- 5 minutes to measurable improvement
- Cyclic sighing: -1.48±1.69 negative affect over 28 days

**Physiological Mechanism**:
- Stimulates stretch-activated baroreceptors
- Triggers vagal activation
- Reduces heart rate & blood pressure
- Enhances prefrontal-amygdala connectivity

**Product Implementation**:
```
Detection triggers:
- Emotional words in text ("заебался", "блять")
- Multiple /stuck rapid fire
- Frequent /pause without /resume

Bot: "Похоже ты в стрессе. Quick recovery (90 sec)?"

[Yes] [No] [What's this?]

┌─ BOX BREATHING (90 sec) ─────┐
│ 6 cycles:                    │
│                              │
│ Вдох  - 4 sec 💨             │
│ Hold  - 4 sec ⏸️             │
│ Выдох - 4 sec 💨             │
│ Hold  - 4 sec ⏸️             │
│                              │
│ [Start Timer]                │
│                              │
│ Science: g=-0.35 stress ↓    │
│ Works in 5 minutes           │
└──────────────────────────────┘

После:
Bot: "Как сейчас? (1-10)"

[1-3: Still bad] [4-7: Better] [8-10: Good]

If Still bad:
→ Escalate to deeper protocol
→ Or suggest 5-min walk
```

**Alternatives** (equivalent evidence):
- Cyclic sighing (double inhale, long exhale)
- Resonant breathing (5-6 breaths/min)
- Cold water на лицо (dive reflex)

**Key Insight**: Physiological regulation fastest (30-60 sec onset), doesn't require cognitive load

### 5. Psychological Detachment (Evening Recovery)

**What**: Mental disengagement from work during non-work time

**Evidence**:
- Strongest negative relationship с exhaustion (Bennett meta, N=26,592)
- Fully mediates workload→stress (>25% variance)
- Predicts next-day performance

**Mechanism**: Detachment → resource restoration → reduced burnout

**4 Recovery Experiences (Sonnentag)**:
1. **Psychological Detachment** - stop thinking about work
2. **Relaxation** - low activation positive affect
3. **Mastery** - learning new challenging skills
4. **Control** - autonomy over leisure time

**Product Implementation**:
```
17:00 end of day:

     Шаг 1: PSYCHOLOGICAL DETACHMENT

     Что выберешь?"

Quick replies:

[🧘 Meditation]             → good
[🏋️ Exercise]              → good
[📺 Light TV]              → ok
[📱 Social media]          → ⚠️ WORST

If Social media:
Bot: "⚠️ СТОП!

     Research (EEG studies):
     - Alpha waves НЕ восстанавливаются 40+ мин
```

**Critical Evidence**:

### 6. Contingent Planning (Interruption Management)

**What**: Planning FOR interruptions, not just tasks

**Evidence**:
- TMP effectiveness weakened by interruptions
- CP maintained engagement regardless (Parke 2018)
- 23 minutes to refocus after major interruption (Mark 2005)

**Problem**: Meeting-heavy schedules create:
- 37% higher stress
- 39% higher frustration
- 15% higher time pressure
- Attention residue (part of attention stuck on prev task)

**Product Implementation**:
```
Morning planning:

Bot: "Сколько обычно незапланированных прерываний в день?"

[Мало 0-1] [Средне 2-3] [Много 4+]

User: "Средне 2-3"

Bot: "Добавлю Contingent Planning:

     1. Interruption buffers в план (1.5ч total)
     2. IF-THEN для interruptions:

     IF прерывают во время [task],
     THEN [recovery action]:

     Варианты recovery:"

[30-sec Ready-to-Resume] [Switch to simple task] [5-min break]

User выбирает

Bot также:
- Batches meetings contiguously (не scattered)
- Adds 30-min transition time после meeting clusters
- Schedules deep work в 90-120min blocks (не 30min gaps)
```

**Ready-to-Resume Plans** (30 seconds):
```
При interruption:

Bot: "Пауза! Быстрый Ready-to-Resume (30 sec):

     1. Что только что закончил?
     2. Где сейчас в текущей задаче?
     3. Следующий шаг при возврате?

     [Quick voice memo] [Text note] [Skip]"

Saves to task state.

Upon /resume:
Bot показывает эти notes → resumption lag ↓30%
```

**Key Insight**: Plan FOR chaos, не против. CP > TMP в high-interruption days.

## 🎯 P1 Features (High Value, Phase 2)

### 7. Temptation Bundling

**What**: Link instantly gratifying activity ONLY to effortful task

**Evidence**:
- +51% gym visits (Milkman 2014, N=226 RCT)
- 10-14% increase at scale (Kirgios 2020, N=6,792)
- 61% paid to continue after study (high subjective value)
- Cost: $9 per person (scalable)

**Mechanism**: Immediate reward → reduces present bias → overcomes temporal discounting

**Product Implementation**:
```
During Top-3 selection, для скучных задач:

Bot: "Code review может быть скучным. Temptation Bundle?"

[Yes] [What's that?]

Bot: "Ты можешь [приятное] ТОЛЬКО во время [задачи].

     Строгая привязка = ключ (+51% выполнения!)

     Что любишь?"

[🎧 Подкасты] [🎵 Музыка] [📺 YouTube] [Other]

User: "подкасты про футбол"

Bot: "Отлично! ПРАВИЛО:
     Футбольные подкасты → ТОЛЬКО код ревью

     ⚠️ Важно:
     Если слушаешь в другое время = эффект исчезает
     Нужна строгая привязка!

     IF-THEN:
     'IF начинаю код ревью,
      THEN включаю подкаст про футбол'"

- Did you listen during task? [Yes/No]

```

**Best For**:
- Boring repetitive tasks
- Long-duration tasks
- Tasks that don't require 100% focus

**Key Insight**: Work WITH present bias, не против. Make effort immediately rewarding.

## 📚 Research Quality Notes

**Highest Quality** (Grade A):
- Multiple RCTs + meta-analyses
- Large N (1000+)
- Low heterogeneity
- Preregistered replications
- Examples: Implementation intentions, Psych detachment, Pref-supply fit

**Good Quality** (Grade B):
- Single RCTs or multiple correlational
- Moderate N (100-1000)
- Some replication
- Examples: Temptation bundling, MCII, Habit formation

**Emerging** (Grade C):
- Observational only
- Small N (<100)
- Single studies
- Examples: Energy-aware, specific patterns

**Failed Replication** (Grade F):
- Major replications null
- Publication bias severe
- Examples: Ego depletion, WM training far transfer
